## 功能与数据基线

- 运行形态：单镜像、单容器、单数据卷；Nginx 8080、Go 8081、PostgreSQL 与 Redis 仅回环。
- 现有页面：`/`、`/join`、`/quiz`、`/result`、`/screen`、`/admin`。
- 现有关键接口：身份、答题、排行、统计、二维码、配置、WebSocket 与单口令后台。
- 解题核心约束：正确答案不下发、题序持久化、服务端时限、`request_id` 幂等、同轮同题唯一计分。
- 现有后台：单口令 `X-Admin-Token`，无账号角色、HttpOnly 会话与结构化审计。
- 现有数据入口：单一幂等 `schema.sql`，无 `schema_migrations` 与 advisory lock。
