# szyca Design Master

> 唯一运行时令牌：`frontend/src/index.css`
>
> 组件视觉实现：`frontend/src/cosmos.css`
>
> 静态品牌文案：`frontend/src/brand.ts`
>
> 设计治理：`szyca` 项目自有，不引用 `Li&Design` 共享子模块
>
> 模板快照：`design-system/szyca/template/`，由 `scripts/export_design_template.py` 生成与校验

## 1. 设计原则

1. 数字深空：全站共享一层固定深空背景、56px 网格和 90 节点星座网络。
2. 代码即美学：终端、编号、等宽标签与细线是结构语言，不作为装饰贴纸。
3. 克制强调：青色主信号，紫色只做点缀；语义色只在成功、警告和错误语境出现。
4. 内容优先：粒子、光晕与玻璃效果不能降低文字可读性或挤压业务表单。
5. 单一事实来源：令牌只在 `index.css`，组件视觉只在 `cosmos.css`，文案降级只在 `brand.ts`。

## 2. 色彩角色

| 角色 | 值 | 用途 |
|---|---|---|
| `--bg-950` | `#05070B` | 页面最深背景 |
| `--bg-850` | `#0A0E1A` | 次级深空层 |
| `--bg-800` | `#0D1422` | 面板与终端底 |
| `--accent-primary` | `#00E5FF` | 主 CTA、链接、焦点、粒子连线 |
| `--accent-secondary` | `#8B5CF6` | Logo、少量标签、次级信号 |
| `--text-primary` | `#E6EDF3` | 标题与主要正文 |
| `--text-secondary` | `#8B949E` | 说明、标签、次级正文 |
| `--line-subtle` | `rgba(255,255,255,.08)` | 玻璃描边、分隔线、网格 |
| `--success` | `#3FB950` | 健康、开启、已完成 |
| `--warning` | `#D29922` | 待机、提醒、宽限 |
| `--error` | `#F85149` | 失败、删除、危险操作 |

已核对深空底上的对比度：主文字约 17:1，次级文字约 6.5:1，青色约 13:1。

## 3. 字体

- 中文：Noto Sans SC / 思源黑体，回退 PingFang SC。
- 西文标题：Space Grotesk。
- 终端、编号、数据与标签：JetBrains Mono。
- H1 桌面 54–82px，移动端 38–58px；细字重 300，负字距不超过 `-0.06em`。
- 正文 16–19px，行高 1.7–1.9；技术标签 7–11px，但不得承载必要长文。
- 数字使用 tabular figures，避免后台数据跳动。

## 4. 空间与形状

- 基础节奏：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px。
- 页面最大宽度 1280px；后台最大宽度 1320px。
- 卡片圆角 10–14px；按钮 8px；胶囊只用于状态。
- 页面横向留白使用 `--page-gutter`；章节间距使用 `--section-space`。
- 桌面 Header 68px，≤820px 为 60px。
- 桌面 Footer 约 82px；≤820px 约 150px。

## 5. 标志性背景

### 固定网格

- 56px × 56px，1px `var(--grid-line)`。
- `position: fixed; inset: 0; pointer-events: none`。
- 通过径向 mask 让网格在边缘自然淡出。

### Canvas 星座

- 90 个节点，110px 内自动连线。
- 连线透明度随距离线性衰减，颜色使用 `--accent-primary`。
- 鼠标 190px 范围内施加轻微吸引力，速度阻尼并限制最大位移。
- DPR 上限 2，单帧仅做约 4,000 次距离判断；DOM 不参与逐帧计算。
- reduced-motion 下保留静态星座，不启动 `requestAnimationFrame`。

## 6. 组件

### Header

- sticky、全宽、深空半透明雾化，底部 1px 渐隐线。
- Logo 使用 45° conic-gradient 方块。
- 导航项至少 44px，高亮为青色描边与 6% 青色底。
- ≤820px 折叠为深色玻璃浮层菜单，`aria-expanded` 同步状态。
- 移动菜单使用两列网格、46px 行高和 12px 圆角，绝对定位在页眉下方；展开时不得改变页眉高度或把正文向下推。
- 菜单支持 Escape、点击外部和路由切换关闭；Escape 后焦点返回菜单触发器。

### 公开内容页标题

- 加入、答题、抽奖、成绩页共用 `PageIntro`：居中、无外框、无面板底色。
- 标题桌面 38–56px，移动端使用同一细字重和负字距；正文说明最大宽度 650px。
- 功能卡仍可保留玻璃表面，但页面级标题不再包裹在大型卡片中。

### Hero

- 左侧：终端启动行、渐变 H1、说明、主/次 CTA、三项统计。
- 右侧：玻璃终端窗口、启动日志、代码对象、SIGNAL 状态与静态几何轨道。
- H1 在桌面两行，320px 起不出现横向溢出或单字孤行。

### 核心模块

- 三张等高玻璃卡片，左上 `[01] [02] [03]`，中英混排标题。
- 每卡有一个线性图标、说明与 `OPEN MODULE` 底部操作语义。
- Hover/focus：上浮 6px、青色描边、`0 24px 60px rgba(0,229,255,.08)`。
- 卡片整体是链接，并提供可见键盘焦点。

### 终端语言

- Hero：`> boot nebula_os ... [OK] ▊`。
- 章节：`$ whoami → 关于我们`、`$ ls ./modules`。
- 后台：`$ systemctl status nebula_os`、`TAIL -F`。
- 页脚：`EOF — 感谢阅读到底部`。

### Footer

- 深空玻璃、淡网格、1px 渐隐顶边。
- 桌面保持单行紧凑信息 + EOF 子行；移动端链接与备案自然换行。
- 页脚链接至少 44px 点击高度。

### 后台工作台

- 四张统计卡：注册用户、参与答题、累计作答、实时在线。
- 增幅仅与上一次 10 秒刷新快照比较，用 ▲/▼ 与文字共同表达。
- 柱状图展示真实用户/参与/在线/题库/影像数量。
- 环形图展示参与转化率，旁边保留原始数值图例。
- 表格展示数据库、Redis、答题状态、内存、协程与运行时长。
- 终端日志由真实运行状态与有权限时的审计记录拼装，不编造趋势。

## 7. 动效

- 入场 680ms，`translateY(24px)` + opacity；卡片错落 120ms。
- Hover 260ms，只改变 transform、颜色、边框与阴影。
- 终端光标 1s steps 闪烁；禁止持续旋转标志与无意义大面积扫描。
- reduced-motion：所有 Reveal 立即可见，Canvas 静止，光标不闪烁。

## 8. 响应式

必测视口：320、360、390、414、480、600、768、820、821、900、1024、1180、1280、1440、1920px，以及 844×390 横屏。

- 820px 是导航与核心模块栅格的单列断点。
- 320px 起禁止文档级横向溢出。
- 300px 以上的业务数据表可仅在自身容器横向滚动；移动后台运行表隐藏冗余标识列，保证状态可见。
- 标题自然换行，禁止 `word-break: break-all`。
- 后台 ≤820px 使用两列导航，≤620px 图表与状态卡单列。
