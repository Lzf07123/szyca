# szyca Design Master

> 唯一实现令牌：`frontend/src/index.css`  
> 品牌文案与静态降级：`frontend/src/brand.ts`  
> 本文件描述规则，不复制另一套可执行令牌。

## 1. 视觉原则

1. 内容优先：标题、活动、答题与抽奖入口比装饰更重要。
2. 轻而不空：用细线、层级和留白组织信息，不用厚重卡片堆叠。
3. 现场与技术感：等宽小字、网格、终端卡片只作辅助识别。
4. 一处配置：公开品牌、导航、页脚、开关和 Section 都来自 `/api/site`。

## 2. 色彩角色

| 角色 | 值 | 用途 |
|---|---|---|
| `--seaglass-deep` | `#25786D` | 主按钮、链接、焦点、标题强调 |
| `--seaglass-light` | `#7FD4C6` | 浅底色、标签和辅助强调 |
| `--ink` | `#102A27` | 正文与大标题 |
| `--muted` | `#526B66` | 次要说明，正文对比度 ≥4.5:1 |
| `--paper` | `#F3F8F6` | 页面背景 |
| `--surface` | `#FFFFFF` | 主要卡片与表单 |
| `--surface-soft` | `#E7F2EE` | 分区背景 |

错误色使用深红，成功和主操作使用海玻璃绿，并始终搭配文字说明。

## 3. 字体与排版

- 中文正文与标题使用系统无衬线字体，回退 `PingFang SC` / `Microsoft YaHei`。
- 技术标注使用 `Press Start 2P`，数字与终端使用 `VT323`，避免用于长段正文。
- H1：桌面 72–112px，移动端 40–66px；负字距只用于大标题。
- H2：桌面 34–72px，移动端 34–48px。
- 正文：16–21px，行高 1.6–1.8；说明 12–14px。

## 4. 间距与形状

采用 4px 基础节奏，主要间距为 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px。

| 令牌 | 值 |
|---|---:|
| `--radius-sm` | 10px |
| `--radius-md` | 18px |
| `--radius-lg` | 28px |

按钮使用胶囊圆角；内容卡使用 18–28px；输入框 10px。

## 5. 组件

### 顶栏

- 桌面高度至少 72px；移动端 64px。
- Logo 进入首页；导航由 `/api/site` 的 `nav` 生成。
- 移动导航按钮 44×44px，`aria-expanded` 同步状态。

### 首页 Section

- 类型固定为 `hero / about / activities / quiz / lottery / join / gallery`。
- 顺序、启停、草稿/发布时间由后台控制。
- 功能关闭时，对应入口和 Section 不渲染。

### 按钮

- 每屏只保留一个主 CTA。
- 主按钮海玻璃底白字；次按钮透明底深色边框。
- Hover 和 Press 不改变布局尺寸，只改变颜色与 1px 位移。

### 表单与反馈

- 输入必须有可见标签。
- 错误靠近字段并使用 `role="alert"`；提交后保持输入。
- 网络等待时按钮禁用并显示进行时文本。

## 6. 动效

- 快速反馈 160ms，常规过渡 260ms，图像缓慢反馈 520ms。
- 仅使用 `transform` 与 `opacity`。
- `prefers-reduced-motion: reduce` 时停止粒子、加载旋转和循环动画，保留完整静态布局。

## 7. 响应式

- 必测宽度：320、390、768、1024、1280、1440px。
- 320px 起禁止文档级横向溢出。
- 1024px 以下首页 Hero 改为单列；719px 以下导航折叠。
- 图片声明尺寸或使用 `aspect-ratio`，非首屏图片 `loading="lazy"`。

## 8. 验收清单

- [ ] 正文与按钮文本对比度 ≥4.5:1。
- [ ] 键盘可完成导航、主要入口和抽奖。
- [ ] 焦点可见且不被粘性顶栏遮挡。
- [ ] 所有主要点击目标 ≥44×44px。
- [ ] 首页只请求一次 `/api/site`。
- [ ] 配置失败时保留静态首页。
- [ ] 无粉紫、霓虹、夸张玻璃或 emoji 结构图标。
