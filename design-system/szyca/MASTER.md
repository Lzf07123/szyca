# szyca Design Master

> 唯一实现令牌：`frontend/src/index.css`  
> 品牌文案与静态降级：`frontend/src/brand.ts`  
> 本文件描述规则，不复制另一套可执行令牌。

## 1. 视觉原则

1. 内容优先：标题、活动、答题与抽奖入口比装饰更重要。
2. 深空舞台、冰白工作面：深色只用于顶栏、Hero、抽奖宣传区和页脚；正文、表单与后台保持冰白高可读表面。
3. 现场与技术感：星点、网格、轨道圆、终端卡片和等宽标注只作辅助识别，不覆盖主要内容。
4. 一处配置：公开品牌、导航、页脚、开关和 Section 都来自 `/api/site`。

## 2. 色彩角色

| 角色 | 值 | 用途 |
|---|---|---|
| `--space-950` / `--space-900` / `--space-800` | `#061922` / `#0A2330` / `#103342` | 深色舞台、顶栏、Hero、页脚 |
| `--brand-700` / `--brand-500` / `--brand-300` | `#1F6F66` / `#25786D` / `#7FD4C6` | 海玻璃信号、链接、状态和浅色强调 |
| `--solar-600` / `--solar-400` | `#A85412` / `#F3A147` | CTA、章节序号和活动强调 |
| `--ink` / `--ink-muted` | `#10262E` / `#526A70` | 浅色表面上的正文与说明 |
| `--on-space` / `--on-space-muted` | `#F3FBFA` / `#AAC1C5` | 深色舞台上的正文与说明 |
| `--paper` / `--surface` | `#F4F9F9` / `#FFFFFF` | 页面背景与工作卡 |

深色区域的主 CTA 使用琥珀；浅色工作区的主操作使用海玻璃绿。错误使用深红并搭配文字，不能只用颜色表达状态。运行时令牌唯一来源为 `frontend/src/index.css`。

## 3. 字体与排版

- 中文正文与标题使用系统无衬线字体，回退 `PingFang SC` / `Microsoft YaHei`。
- 技术标注使用 `Press Start 2P`，数字与终端使用 `VT323`，避免用于长段正文。
- H1：桌面 72–112px，移动端 40–66px；负字距只用于大标题。
- H2：桌面 34–72px，移动端 34–48px。
- 正文：16–21px，行高 1.6–1.8；说明 12–14px。

## 4. 间距与形状

采用 4px 基础节奏，主要间距为 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96px。

| 令牌 | 值 |
|---|---:|
| `--radius-sm` | 10px |
| `--radius-md` | 18px |
| `--radius-lg` | 28px |

按钮使用胶囊圆角；内容卡使用 18–28px；输入框 10px。

## 5. 组件

### 顶栏

- 桌面高度至少 72px；移动端 64px。
- 顶栏使用深空基底，导航默认浅灰蓝，当前项与悬停使用琥珀/海玻璃信号。
- 上传 Logo 放置在浅色承载面内，避免深色或透明图片在顶栏消失。
- Logo 进入首页；导航由 `/api/site` 的 `nav` 生成。
- 移动导航按钮 44×44px，`aria-expanded` 同步状态。
- 移动导航展开后使用深空面板与浅色链接，不使用旧的白底菜单。

### 首页 Section

- 类型固定为 `hero / about / activities / quiz / lottery / join / gallery`。
- 顺序、启停、草稿/发布时间由后台控制。
- 功能关闭时，对应入口和 Section 不渲染。

### 按钮

- 每屏只保留一个主 CTA。
- 浅色工作区主按钮使用海玻璃底白字；深色舞台主按钮使用琥珀底白字；次按钮使用同上下文描边。
- Hover 和 Press 不改变布局尺寸，只改变颜色与 1px 位移。

### 页脚

- 使用深空基底和细网格，正文保持浅色；链接悬停转为海玻璃浅色。
- 备案号只在真实配置存在时展示，并与版权信息保持同一可读层级。

### 表单与反馈

- 输入必须有可见标签。
- 错误靠近字段并使用 `role="alert"`；提交后保持输入。
- 网络等待时按钮禁用并显示进行时文本。

## 6. 动效

- 快速反馈 160ms，常规过渡 260ms，图像缓慢反馈 520ms。
- 仅使用 `transform` 与 `opacity`。
- 粒子组合只使用海玻璃绿与琥珀；从 `index.css` 的 `--particle-*` 令牌读取，不新增第二套装饰色。
- `prefers-reduced-motion: reduce` 时停止粒子、加载旋转和循环动画，保留完整静态布局。

## 7. 响应式

- 必测宽度：320、390、768、1024、1280、1440px。
- 320px 起禁止文档级横向溢出。
- 1024px 以下首页 Hero 改为单列；719px 以下导航折叠。
- 图片声明尺寸或使用 `aspect-ratio`，非首屏图片 `loading="lazy"`。

## 8. 验收清单

- [ ] 正文与按钮文本对比度 ≥4.5:1。
- [ ] 键盘可完成导航、主要入口和抽奖。
- [ ] 焦点可见且不被粘性顶栏遮挡。
- [ ] 所有主要点击目标 ≥44×44px。
- [ ] 首页只请求一次 `/api/site`。
- [ ] 配置失败时保留静态首页。
- [ ] 深色区域的正文与按钮对比度 ≥4.5:1。
- [ ] 无粉色、AI 紫、霓虹渐变、夸张玻璃或 emoji 结构图标。
