# 首页页面覆盖规则

- 页面结构固定为 Hero → `$ whoami` 介绍带 → 核心模块 → 页脚；抽奖开启时在模块后增加紧凑事件信号条。
- Hero 左侧使用 `> boot nebula_os ... [OK] ▊`、渐变主标题、一个主 CTA、一个幽灵 CTA 与三项系统统计。
- Hero 右侧使用玻璃终端、代码对象和静态轨道标记；背景照片只作低透明度纹理。
- `$ whoami → 关于我们` 使用一条紧凑玻璃介绍带，活动类型以小型等宽标签呈现，不再占据独立大章节。
- `$ ls ./modules` 下固定呈现答题中心、实时排行、加入我们三张卡片；关闭的功能不渲染对应卡。
- 每张模块卡使用 `[01]`–`[03]` 编号、中英混排标题、线性图标和 `OPEN MODULE` 操作语义。
- 抽奖开启时渲染 `#lottery` 事件条，使用紫色低透明信号底，不得挤压三卡主结构。
- 桌面临界以下保持自然换行；820px 起三张模块卡改为单列。
- 页脚以 `EOF — 感谢阅读到底部` 收尾。
